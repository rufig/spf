загрузка spf-min.wasm…

Раскраска токенов ниже определяется живым словарём spf64-wasm: immediate-слова (управление) — одним цветом, обычные слова словаря — другим, неизвестные — подчёркнуты. Комментарии, строки, числа, определения и локалы — по правилам поверхности spf4.

\ пример: факториал и локалы
: FACT ( n -- n! )
  DUP 2 < IF DROP 1 EXIT THEN
  DUP 1- RECURSE * ;

: GREET { name-a name-u \ cnt -- }
  S" Hello, " TYPE name-a name-u TYPE
  0x2A EMIT CR ;

VARIABLE COUNTER
: BUMP ( -- ) COUNTER 1+! FROBNICATE ;   \ FROBNICATE словарь не знает
7 FACT . CR
